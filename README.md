# 青の時間

夕暮れと夜のあいだ、村の窓に灯りがともる頃の写真を、写真集をめくるように流すスクリーンセーバーです。
チルな音楽は手元のアルバムから。写真はその場で取ってきて眺めるだけで、どこにも保存しません。

公開ページ: https://hogasahara.github.io/screen/

## 使いかた

1. 上のページを開く（写真が集まるまで少し待つ）
2. `F` キー、または右上の「全画面」で全画面にする
3. `S` キー、または「設定」でテーマを選ぶ（複数可）
   - ブルーモーメント／プリンス・エドワード島／雪と灯り／田園と空
   - アンコモン・プレイス（アメリカ）：スティーブン・ショアの写真集の方向。交差点、モーテル、ガソリンスタンド、住宅街
   - 日本の街：都会以外の日本の家並みや店
4. 気に入った一枚は `L` キーか「お気に入り」で登録。設定の「お気に入り」から JSON で書き出せます
5. 「音楽」の「曲を選ぶ」で手元の曲を選ぶ（選んだ順に繰り返す）
6. 自分の写真で眺めたいときは「自分のフォルダ」の「写真を選ぶ」

音楽も写真も、この端末の中だけで使われ、どこにも送られません。

### キー

| キー | 動き |
| --- | --- |
| `Space` | 止める・進める |
| `→` | 次の一枚 |
| `L` | お気に入りに入れる・外す |
| `F` | 全画面 |
| `C` | キャプションの表示・非表示 |
| `D` | 検索語の表示（調整用） |
| `S` | 設定を開く・閉じる |
| `Esc` | 設定を閉じる |

### 写真の出どころ

- **Wikimedia Commons**（既定、鍵いらず）
- **Unsplash**（[無料の Access Key](https://unsplash.com/developers) が必要、写真の質が高い）
- **Flickr**（API の鍵は Pro アカウント限定。持っている場合だけ）
- **お気に入りだけ**（登録した写真を繰り返す）
- **自分のフォルダ**

鍵は設定画面に貼るだけです。ページの URL にだけ残り、どこにも送られません。

検索語はテーマごとに「主題」と「差し込み」に分かれ、差し込み（踏切や看板の寄りなど）は控えめに出ます。
同じ写真家の連作や同じ場所は後ろに回し、全部見終わったら、見た写真を混ぜ直して繰り返します。
Wikimedia Commons では、風景のテーマはコミュニティが認定した「秀逸な画像」「品質画像」から先に取り、
「アンコモン・プレイス」は米国議会図書館の John Margolies のアーカイブ（パブリックドメイン）から取ります。
設定の「検索語の当たりを見る」で、語ごとに取れた写真を一覧にできます。写真を押すとお気に入りに入ります。

設定はページの URL（`#` 以降）に残ります。ブックマークしておくと同じ設定で開けます。
Unsplash や Flickr の鍵も URL にだけ残るので、URL を人に渡すときは鍵の部分に注意してください。

### ホーム画面に追加

スマートフォンやタブレットでは、ブラウザの「ホーム画面に追加」で、
次からはブラウザの枠なしの全画面で起動できます。

## 公開のしくみ

`main` ブランチに push すると GitHub Actions（`.github/workflows/pages.yml`）が
`index.html`、`manifest.json`、アイコンだけを集めて GitHub Pages に配置します。
初回だけ、リポジトリの Settings → Pages → Build and deployment → Source を **GitHub Actions** にしてください。

## 手元で開く

ビルドはいりません。`index.html` をブラウザで開くだけで動きます。
