青の時間

夕暮れと夜のあいだ、村の窓に灯りがともる頃の写真を、写真集をめくるように流します。

写真の出どころ

unsplash.com/developers でアプリを1つ作ると発行されます。鍵はこのページのURLにだけ残ります。開発モードは1時間に50回まで。テーマを切り替えても取ってきた分は捨てないので、眺めているだけなら足ります。
Flickr の API キーはいま Pro アカウントにしか発行されません。持っている場合だけ。CC ライセンスの写真を、反応の多かった順に取ります。
選んだ写真はこの端末の中だけで使われ、どこにも送られません。

テーマ

Wikimedia Commons・Unsplash・Flickr のときに効きます。 いま選んでいる出どころとテーマの語ごとに、取れた写真を一覧にします。Unsplash では語の数だけ要求を使います。

見せかた

切り替える間隔30秒
青の深さ28
雨なし
窓ガラス越しに眺めます。右へ行くほど強い雨に。R で段階的に切り替え。
雫の陰影40
左は淡く明るい雫、右は影の濃い雫。

お気に入り

眺めている一枚を L か「お気に入り」で登録。この端末の中に残ります。書き出した JSON には写真のページ、撮影者、出どころ、当たった検索語が入るので、共有や語の調整に使えます。

音楽

手元のアルバムから何曲でも。選んだ順に繰り返します。
