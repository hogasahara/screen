# rain/

雨の窓ガラスの描画に使う [raindrop-fx](https://github.com/SardineFish/raindrop-fx)（SardineFish、MIT License）の
ビルド済みファイル `raindrop-fx.js`（npm の raindrop-fx@1.0.8 `bundle/index.js` そのまま）と、そのライセンス。

`index.html` は設定の「雨」を 0 より大きくしたときだけこのファイルを読み込む。WebGL2 が必要。

`sounds/` には窓越しの雨の実録音（Freesound、CC0）が 3 本入っている。出どころは `sounds/README.md`。
